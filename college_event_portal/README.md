# College Event Management Portal

A modern, responsive, and robust college event registration portal built with Flask and SQLite.

## Features
- **Student Dashboard**: Browse events, view upcoming events, register, cancel registration, and view profile.
- **Admin Dashboard**: Create, edit, and delete events. View all registrations and platform statistics.
- **Modern UI**: Built with HTML, CSS, JavaScript using CSS Grid/Flexbox, glassmorphism design principles, and smooth animations.
- **Database**: SQLite, created automatically upon starting the application.

## Setup Instructions

1. Ensure you have Python installed.
2. Install the required dependencies:
   ```bash
   pip install -r requirements.txt
   ```
3. Run the application:
   ```bash
   python app.py
   ```
   *The database `database.db` will be created and populated with sample data on the first run.*

4. Open your browser and navigate to: `http://localhost:5000`
